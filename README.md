# morje 
## GitHub-työpajan yhteenveto

### 1. Omat muutokset
Molemmat tekijät loivat omat muutoksensa ja tallensivat ne GitHubiin committeina.

### 2. Katselmointi
Molemmat tekijät loivat oman haaran ja Pull Requestin. Katselmoimme toistemme muutokset ja yhdistimme ne päähaaraan.

### 3. Yhdistämisristiriita
Ristiriita syntyi, koska muokkasimme samaa riviä eri haaroissa eri tavalla. GitHub ei pystynyt yhdistämään muutoksia automaattisesti.

Ratkaisimme ristiriidan valitsemalla yhteisen tekstin, poistamalla ristiriitamerkit ja tallentamalla ratkaisun. Lopuksi yhdistimme muutoksen päähaaraan.

### 4. Työn tila
Valmis. Harjoittelimme committeja, haarojen luomista, Pull Requesteja, katselmointia ja yhdistämisristiriidan ratkaisemista.
